📊 定时推送

✅ 由独立调度进程运行，避免多 Worker 重复推送。

🔐 管理令牌

令牌仅保存在当前浏览器内存中，用于手动和测试推送。

⏰ 推送时间

• 工作日 09:02 - 日盘开盘（取 09:00–09:05 首个有效报价）

• 工作日 13:32 - 午盘开盘（取 13:30–13:35 首个有效报价）

• 工作日 15:32 - 日线收盘（官方完整日线发布后）

• 手动模拟收盘：使用最新已发布日线，并在消息中标注“模拟”。

• 工作日 20:02 - 夜盘开盘（归属下一交易日）

• 周末和节假日以源站实际行情为准；无有效报价时不发送。

🛠️ 运行方式

python gold_service.py --scheduler-only

通过进程管理器启停调度器；Web 界面不再提供启停操作。

🔌 API 接口文档

📊 黄金与白银价格API

# 获取实时价格 curl http://localhost:5080/api/gold/spot_quotations_sge # 获取历史价格 (最近5天) curl http://localhost:5080/api/gold/spot_hist_sge?days=5 # 运行后端策略回测（MA5/20、MA10/30、MACD、KDJ） curl 'http://localhost:5080/api/gold/backtest?strategy=ma5_20&start=2025-01-01&initial_cash=100000&order_amount=10000' # 打开独立回测页面 open http://localhost:5080/backtest # 当前交易时段、时区及夜盘归属 curl http://localhost:5080/api/market/session # 获取API信息 curl http://localhost:5080/api/gold/info # 获取实时白银价格 curl http://localhost:5080/api/silver/spot_quotations_sge # 获取白银历史价格 (最近5天) curl http://localhost:5080/api/silver/spot_hist_sge?days=5

🔔 推送服务API

# 先在服务端配置 GOLD_ADMIN_TOKEN；以下管理接口都需请求头。 export GOLD_ADMIN_TOKEN='请替换为随机令牌' # 调度器由独立进程管理，启停接口已停用；此接口仅返回调度说明 curl -H "X-Admin-Token: $GOLD_ADMIN_TOKEN" http://localhost:5080/api/service/status # 测试及手动推送 curl -X POST -H "X-Admin-Token: $GOLD_ADMIN_TOKEN" http://localhost:5080/api/push/test curl -X POST -H "X-Admin-Token: $GOLD_ADMIN_TOKEN" http://localhost:5080/api/push/opening curl -X POST -H "X-Admin-Token: $GOLD_ADMIN_TOKEN" 'http://localhost:5080/api/push/closing?mode=latest' curl -X POST -H "X-Admin-Token: $GOLD_ADMIN_TOKEN" http://localhost:5080/api/push/kdj-signal curl -X POST -H "X-Admin-Token: $GOLD_ADMIN_TOKEN" http://localhost:5080/api/push/night-opening
